  <files>backend/app/matching/privacy.py, backend/app/api/v1/matching.py, backend/app/main.py</files>
  <read_first>backend/app/matching/engine.py, backend/app/api/v1/evidence.py</read_first>
  <action>
    1. Create backend/app/matching/privacy.py:
       - MatchPrivacyPolicy class:
         - `sanitize_match_response(match: MediaMatchRecord, requesting_investigation_id: str, db_session: AsyncSession) -> Dict[str, Any]`:
           - If matched asset belongs to requesting_investigation_id:
             - Scope: "LOCAL_INVESTIGATION".
             - Return full context (submission details, captions).
           - If matched asset was observed elsewhere in the global index:
             - Scope: "GLOBAL_INDEX_ANONYMIZED".
             - Return ONLY: `matched_media_asset_id`, `classification`, `raw_metrics`, `method`, `algorithm_version`, `is_video_frame_match`, `matched_frame_timestamp_ms`, `occurrence_count`.
             - EXCLUDE: `investigation_id`, `investigation_title`, `submission_id`, `caption`, `claimed_event`, `claimed_date`, `claimed_location`, `investigator_name`, `submission_created_at`.
    2. Create backend/app/api/v1/matching.py:
       - POST /api/v1/investigations/{investigation_id}/evidence/{evidence_id}/match:
         - Runs MatchEngine and applies MatchPrivacyPolicy.
       - GET /api/v1/investigations/{investigation_id}/evidence/{evidence_id}/matches:
         - Retrieves existing match records sanitized by MatchPrivacyPolicy.
       - POST /api/v1/indexing/reindex:
         - Controlled reindex of existing assets.
    3. Register matching router in backend/app/main.py.
  </action>
