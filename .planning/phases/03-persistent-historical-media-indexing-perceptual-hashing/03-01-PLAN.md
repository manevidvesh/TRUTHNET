    1. MediaHasher class:
       - `compute_image_fingerprints(image_path: Path) -> Dict[str, Any]`:
         - Opens image with Pillow.
         - Computes pHash (`imagehash.phash`), dHash (`imagehash.dhash`), aHash (`imagehash.average_hash`), colorHash (`imagehash.colorhash`).
         - Converts image to grayscale OpenCV array.
         - Computes ORB keypoints and descriptors (`cv2.ORB_create(nfeatures=1000)`).
         - Returns: { phash_hex, dhash_hex, ahash_hex, colorhash_hex, orb_keypoints, orb_descriptors, keypoint_count }
       - `hamming_distance(hash1_hex: str, hash2_hex: str) -> int`:
         - Computes bitwise XOR popcount between two 64-bit hexadecimal hash strings.
  </action>
