<task type="auto">
  <name>Task 2: Implement Deterministic Preprocessor and Secure Descriptor Store</name>
  <files>backend/app/indexing/preprocessing.py, backend/app/indexing/descriptor_store.py</files>
  <read_first>backend/app/core/storage.py</read_first>
  <action>
    1. Create backend/app/indexing/preprocessing.py:
       - ImagePreprocessor class:
         - `preprocess_image(image_path: Path) -> Tuple[Image.Image, np.ndarray, Dict[str, Any]]`:
           - Applies `ImageOps.exif_transpose` for EXIF orientation normalization.
           - If image has alpha channel or palette with transparency: composite onto white background `(255, 255, 255)`.
           - Converts to standard RGB PIL Image.
           - Converts to 8-bit grayscale numpy array for OpenCV feature detection.
           - Records `preprocessing_version = "PREPROCESS-V1"`.
    2. Create backend/app/indexing/descriptor_store.py:
       - DescriptorStore class:
         - `save_descriptors(sha256_hash: str, descriptors: Optional[np.ndarray]) -> Optional[str]`:
           - Saves numpy array to `data/derived/descriptors/{sha256[:2]}/{sha256}.npy`.
           - Returns relative path string.
         - `load_descriptors(rel_path: str) -> Optional[np.ndarray]`:
           - Validates safe path inside `data/derived/descriptors/`.
           - Checks file size (< 2MB).
           - Loads with `np.load(..., allow_pickle=False)`.
           - Validates `ndim == 2`, `shape[1] == 32`, and `dtype == np.uint8`.
           - Returns numpy array or None if corrupt/invalid.
  </action>
  <verify>python -c "import sys; sys.path.append('backend'); from app.indexing.preprocessing import preprocessor; from app.indexing.descriptor_store import descriptor_store; print(preprocessor, descriptor_store)"</verify>
  <acceptance_criteria>
    - Preprocessor normalizes orientation and transparency deterministically.
    - Descriptor store validates files on load with allow_pickle=False and bounds checking.
  </acceptance_criteria>
