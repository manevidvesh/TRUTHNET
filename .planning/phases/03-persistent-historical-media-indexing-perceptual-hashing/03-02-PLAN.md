  <name>Task 2: Implement Geometric Feature Verifier with RANSAC Homography Check</name>
  <files>backend/app/matching/geometric.py</files>
  <read_first>backend/app/indexing/descriptor_store.py</read_first>
  <action>
    Create backend/app/matching/geometric.py:
    1. GeometricVerifier:
       - `verify_geometry(query_descs: Optional[np.ndarray], candidate_descs: Optional[np.ndarray], min_keypoints: int = 10, min_inliers: int = 12, min_inlier_ratio: float = 0.20) -> Dict[str, Any]`:
         - Start timer.
         - Check keypoint presence:
           - If query_descs is None or len(query_descs) < min_keypoints:
             return { "status": "INSUFFICIENT_FEATURES", "reason": "Query image has fewer than min_keypoints", "keypoints_query": 0 if query_descs is None else len(query_descs) }
           - If candidate_descs is None or len(candidate_descs) < min_keypoints:
             return { "status": "INSUFFICIENT_FEATURES", "reason": "Candidate image has fewer than min_keypoints", "keypoints_candidate": 0 if candidate_descs is None else len(candidate_descs) }
         - Match with `cv2.BFMatcher(cv2.NORM_HAMMING)`.
         - Lowe's ratio test ($0.75$).
         - If good matches < 4:
           return { "status": "NO_HOMOGRAPHY_POSSIBLE", "good_matches": len(good_matches), "inlier_count": 0, "inlier_ratio": 0.0 }
         - Extract coordinates and run `cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)`.
         - Compute inliers and inlier ratio.
         - Stop timer.
         - Return: {
             "status": "GEOMETRIC_MATCH_CONFIRMED" if (inlier_count >= min_inliers and inlier_ratio >= min_inlier_ratio) else "GEOMETRIC_TRANSFORMATION_REJECTED",
             "is_geometric_match": inlier_count >= min_inliers and inlier_ratio >= min_inlier_ratio,
             "keypoints_query": len(query_descs),
             "keypoints_candidate": len(candidate_descs),
             "good_matches": len(good_matches),
             "inlier_count": inlier_count,
             "inlier_ratio": round(inlier_ratio, 3),
             "verification_latency_ms": round(elapsed_ms, 2),
             "homography_matrix": H.tolist() if H is not None else None
           }
  </action>

    2. Implement backend/app/matching/engine.py:
       - MatchEngine class:
         - Decision rules:
           - If SHA-256 match: `EXACT_FILE_MATCH` (Exact binary identity).
           - If keypoints < 10 on query or candidate: `INSUFFICIENT_MATCH_EVIDENCE`.
           - If pHash <= 4 and dHash <= 4: `NEAR_DUPLICATE`.
           - If geometric verifier confirms homography (inliers >= 12, ratio >= 0.20): `SAME_PHOTOGRAPH_MODIFIED`.
           - If perceptual candidate or feature matches exist but RANSAC fails or inliers below threshold: `POSSIBLE_VISUAL_SIMILARITY`. Does NOT infer same event or same scene.
           - If no candidates within threshold: `NO_LOCAL_MATCH_FOUND` (with local repository bound disclaimer).
         - Exposes raw measurements without inventing confidence percentages.
         - External reverse-image search: reports `UNAVAILABLE` with clear diagnostic reason.

       - Test crop 30% + rotation -> SAME_PHOTOGRAPH_MODIFIED.
       - Test two different photos of same landmark -> POSSIBLE_VISUAL_SIMILARITY (verifies failed homography is NOT classified as proof of same photo or same event).
       - Test blank/textureless image -> INSUFFICIENT_MATCH_EVIDENCE.
       - Test unrelated image -> NO_LOCAL_MATCH_FOUND.
