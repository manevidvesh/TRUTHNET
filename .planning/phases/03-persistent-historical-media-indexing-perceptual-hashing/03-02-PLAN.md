  <name>Task 2: Implement Geometric Feature Verifier with RANSAC Homography Check</name>
  <files>backend/app/matching/geometric.py</files>
  <read_first>backend/app/indexing/hasher.py</read_first>
  <action>
    Create backend/app/matching/geometric.py:
    1. GeometricVerifier class:
       - `verify_geometry(query_kps, query_descs, candidate_kps, candidate_descs) -> Dict[str, Any]`:
         - Use `cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=False)`.
         - Match with k=2 and apply Lowe's ratio test (`m.distance < 0.75 * n.distance`).
         - If good_matches < 4: return { is_geometric_match: False, inlier_count: 0, inlier_ratio: 0.0, reason: "Insufficient feature correspondences" }.
         - Extract coordinates: `src_pts`, `dst_pts`.
         - Run `cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)`.
         - If H is None: return { is_geometric_match: False, inlier_count: 0, inlier_ratio: 0.0, reason: "Homography degenerate or collinear" }.
         - Inlier count = sum(mask). Inlier ratio = inlier_count / len(good_matches).
         - Return:
           {
             "is_geometric_match": inlier_count >= 12 and inlier_ratio >= 0.20,
             "inlier_count": inlier_count,
             "inlier_ratio": round(float(inlier_ratio), 3),
             "total_good_matches": len(good_matches),
             "homography_matrix": H.tolist() if H is not None else None
           }
  </action>

  <acceptance_criteria>

    2. Implement backend/app/matching/engine.py:
       - MatchEngine class:
         - `match_evidence(db_session: AsyncSession, evidence_id: str) -> List[MediaMatchRecord]`:
           - Obtains source EvidenceSubmission and MediaAsset.
           - Runs CandidateRetrieval.
           - If SHA-256 match -> classification: "EXACT_FILE_MATCH".
           - For perceptual candidates:
             - If pHash <= 4 and dHash <= 4 -> classification: "NEAR_DUPLICATE".
             - If geometric verifier confirms projective match (inlier_ratio >= 0.20, inliers >= 12) -> classification: "SAME_PHOTOGRAPH_MODIFIED".
             - If good feature matches >= 15 but geometric homography fails -> classification: "POSSIBLE_SAME_SCENE_OR_EVENT" (disclaimer: distinct photograph of same scene/landmark).
             - If hamming <= 10 without keypoint consensus -> classification: "VISUALLY_RELATED_CONTENT".
           - If no candidates pass -> classification: "NO_LOCAL_MATCH_FOUND" (disclaimer: search was bounded to local repository of N assets; does not prove media never appeared elsewhere).
           - Handles external reverse search: explicitly appends/returns `external_reverse_search: { status: "UNAVAILABLE", reason: "External reverse-image search provider is not integrated." }`.
    3. Write backend/tests/test_geometric_matching.py:
       - Test exact file match.
       - Test cropped/rotated image classified as SAME_PHOTOGRAPH_MODIFIED.
       - Test two different pictures of same landmark classified as POSSIBLE_SAME_SCENE_OR_EVENT.
       - Test unrelated image classified as NO_LOCAL_MATCH_FOUND.
  </action>
