<task type="auto">
  <name>Task 2: Implement Real Language Detector, Claim Normalizer, and Hybrid Extractor</name>
  <files>backend/app/claims/language.py, backend/app/claims/normalizer.py, backend/app/claims/extractor.py, backend/app/claims/__init__.py</files>
  <read_first>backend/app/models/claim.py, backend/app/services/pipeline.py</read_first>
  <action>
    1. Create backend/app/claims/language.py:
       - `LanguageDetector`:
         - Uses `langdetect` for statistical n-gram language detection.
         - Returns `(lang_code, method, confidence)`:
           - If `langdetect` is installed and succeeds: returns `(code, "langdetect_ngram", prob)`.
           - If `langdetect` is unavailable or text is too short: inspects Unicode blocks (Devanagari -> "hi", Telugu -> "te", Latin -> "en"), returning `(code, "unicode_script_fallback", None)` with honest `None` confidence.
         - Supports translation provenance tracking structure (original_text, translated_text, engine).
    2. Create backend/app/claims/normalizer.py:
       - `ClaimNormalizer`:
         - Normalizes temporal expressions into ISO-8601 (dates, years, months).
         - Normalizes geographical locations against gazetteer centroids.
         - Normalizes numerical quantities, currencies, and percentages.
         - Preserves verbatim substrings and original case.
    3. Create backend/app/claims/extractor.py:
       - `ClaimExtractor`:
         - Implements a hybrid pipeline:
           1. Segmentation: splits text into sentence boundaries and records exact character offsets `[start_char, end_char]` in original source text.
           2. Factual Classification: filters out pure subjective opinions, insults, and rhetorical questions, setting `is_factual_assertion=False`.
           3. Atomic Decomposition: breaks compound clauses ("The bridge collapsed and officials fled") into discrete propositions.
           4. Proposition Structuring: parses Subject, Predicate (capturing negation like "did not", "never", "refused"), Object, and Qualifiers.
           5. Entity Extraction: extracts named entities (persons, orgs, locations, dates, numbers) with offsets.
           6. Language Tracking: integrates `LanguageDetector` to record language and provenance.
         - Handles modalities: CAPTION, RAW_TEXT, OCR_EXTRACTED, and TRANSCRIPT.
         - Bounded Fallback: if external NLP model is unavailable, executes deterministic syntax and pattern parsing, explicitly setting `extraction_method="DETERMINISTIC_FALLBACK"` and `extraction_confidence=None`.
    4. Register claim extraction step in backend/app/services/pipeline.py during submission intake.
  </action>
  <verify>python -c "import sys; sys.path.insert(0, 'backend'); from app.claims.extractor import claim_extractor; print(claim_extractor)"</verify>
  <acceptance_criteria>
    - Language detection distinguishes English, Hindi, and Telugu with genuine detection methods.
    - Atomic claims preserve character offsets [start_char, end_char] matching source text.
    - Negation and attribution are properly separated.
    - Opinions and rhetorical questions are marked with is_factual_assertion=False.
  </acceptance_criteria>
