<task type="auto">
  <name>Task 2: Implement Claim Extractor and Normalizer with Multilingual Support</name>
  <files>backend/app/claims/extractor.py, backend/app/claims/normalizer.py, backend/app/claims/__init__.py</files>
  <read_first>backend/app/models/claim.py</read_first>
  <action>
    1. Create backend/app/claims/normalizer.py:
       - `ClaimNormalizer`:
         - Normalizes temporal expressions (e.g., "yesterday", "15 March 2026", "2026-03-15") into ISO-8601 dates.
         - Normalizes numbers, percentages, and currencies.
         - Cleans whitespace and quotation markers.
         - Extracts named entities using regex patterns for geopolitical locations, government organizations, and prominent titles.
    2. Create backend/app/claims/extractor.py:
       - `ClaimExtractor`:
         - `extract_claims_from_submission(submission, extraction_record) -> List[Dict]`:
           - Extracts assertions from `submission.caption`, `submission.raw_text`.
           - Extracts assertions from `extraction_record.ocr_result.get("text")`.
           - Extracts assertions from `extraction_record.transcription_result.get("transcript")`.
           - Identifies language (detects Devanagari script for Hindi, Telugu unicode range for Telugu, ASCII/Latin for English).
           - Preserves verbatim text and records translation provenance.
    3. Update backend/app/services/pipeline.py to trigger claim extraction on submission intake.
  </action>
  <verify>python -c "import sys; sys.path.insert(0, 'backend'); from app.claims.extractor import claim_extractor; print(claim_extractor)"</verify>

  </acceptance_criteria>
