<objective>
Implement the Retrieval-First Evidence Discovery subsystem and Multi-Signal Source Independence Analyzer, supporting local ClaimReview records, Google Fact Check API, and SSRF-hardened web search with 4-dimensional independence analysis.

Purpose: Grounds claim verification in observable authoritative sources and prevents 10 syndicated copies of the same wire story from masquerading as 10 independent witnesses.
Output: `RetrievedSourceRecord`, `SourceIndependenceRecord`, retrieval adapters, multi-signal analyzer, and adversarial test suite.
</objective>

<task type="auto">
  <name>Task 2: Implement Concrete Retrieval Adapters and Multi-Signal Independence Analyzer</name>
  <files>backend/app/retrieval/adapters/local_claimreview.py, backend/app/retrieval/adapters/google_factcheck.py, backend/app/retrieval/adapters/web_scraper.py, backend/app/retrieval/source_independence.py, backend/app/retrieval/service.py, backend/app/retrieval/__init__.py</files>
  <read_first>backend/app/models/source.py, backend/app/claims/extractor.py, backend/app/utils/security.py</read_first>
  <action>
    1. Create backend/app/retrieval/adapters/local_claimreview.py:
       - `LocalClaimReviewAdapter`:
         - Loads curated JSON-LD dataset from `backend/app/retrieval/data/claimreview_archive.json`.
         - Matches claims via keyword, entity, and token overlap.
         - Preserves `claimReviewed`, `reviewRating`, `author`, `datePublished`, and canonical URL.
         - 100% offline availability.
    2. Create backend/app/retrieval/adapters/google_factcheck.py:
       - `GoogleFactCheckAdapter`:
         - Queries Google Fact Check Tools API (`claims:search`) when `GOOGLE_FACTCHECK_API_KEY` is set.
         - If key is unconfigured: returns status `UNCONFIGURED` and empty list without failing.
         - If network fails or quota is exceeded: returns status `UNAVAILABLE` or `RATE_LIMITED`. Zero fabricated responses.
    3. Create backend/app/retrieval/adapters/web_scraper.py:
       - `WebScraperAdapter`:
         - Enforces Phase 1 SSRF protections: validates target IPs against RFC 1918, loopback, link-local, cloud metadata (`169.254.169.254`), and prevents DNS rebinding.
         - Re-checks destination on all HTTP redirects (max 3 redirects).
         - Extracts clean text snippets strictly capped at $\le 500$ characters with character offsets.
    4. Create backend/app/retrieval/source_independence.py:
       - `SourceIndependenceAnalyzer`:
         - Implements multi-signal dependency analysis across 4 dimensions:
           1. Publisher independence: domain, parent entity.
           2. Reporting independence: wire markers ("PTI", "ANI", "Reuters", "AP", "AFP"), citations to original reporting ("as reported by", "speaking to").
           3. Evidence independence: shared documents vs distinct reporting.
           4. Source-of-origin independence: primary eyewitnesses vs citing single viral tweet.
         - Separates shared quotations from prose text overlap.
         - Computes 5-gram Jaccard overlap on non-quoted sentences.
         - Groups dependent articles into single clusters.
         - Sets `independence_assessment`:
           - If `total_sources > 1` and `independent_sources == 1`: `WIRE_REPUBLICATION_CHAIN`.
           - If `independent_sources >= 2`: `INDEPENDENT_CORROBORATION`.
           - If `total_sources == 1`: `SINGLE_SOURCE_ORIGIN`.
           - If attribution is missing, conflicting, or unknown: `UNRESOLVED_DEPENDENCY`.
    5. Create backend/app/retrieval/service.py:
       - `RetrievalService`:
         - Coordinates adapters, preserves passage snippets, executes `SourceIndependenceAnalyzer`, and handles offline/missing states honestly.
  </action>
