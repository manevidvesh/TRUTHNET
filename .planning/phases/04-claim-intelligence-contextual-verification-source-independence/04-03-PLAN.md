<task type="auto">
  <name>Task 2: Implement Retrieval Service and Source Independence Analyzer</name>
  <files>backend/app/retrieval/service.py, backend/app/retrieval/source_independence.py, backend/app/retrieval/factcheck_adapter.py, backend/app/retrieval/__init__.py</files>
  <read_first>backend/app/models/source.py, backend/app/claims/extractor.py</read_first>
  <action>
    1. Create backend/app/retrieval/factcheck_adapter.py:
       - `FactCheckAdapter`:
         - Queries curated local fact-check database (ClaimReview format) and public fact-check endpoints.
         - Extracts verdict ("False", "Misleading", "Partly False", "True"), passage snippet, publisher, and published date.
    2. Create backend/app/retrieval/source_independence.py:
       - `SourceIndependenceAnalyzer`:
         - Detects wire service bylines ("PTI", "Press Trust of India", "ANI", "Reuters", "Associated Press", "AP", "AFP").
         - Computes 5-gram Jaccard text overlap between retrieved passage snippets.
         - Groups articles sharing syndication tags or Jaccard similarity > 0.60 into a single republication cluster.
         - Computes `independent_sources_count` = count of distinct clusters.
         - Classifies independence:
           - If `total_sources > 1` and `independent_sources == 1`: `WIRE_REPUBLICATION_CHAIN`.
           - If `independent_sources >= 2`: `INDEPENDENT_CORROBORATION`.
           - If `total_sources == 1`: `SINGLE_SOURCE_ORIGIN`.
    3. Create backend/app/retrieval/service.py:
       - `RetrievalService`:
         - Orchestrates claim query retrieval, passage snippet preservation, and source independence analysis.
         - Enforces explicit abstention: if 0 fact-checks or sources are retrieved, records `status="NO_RECORDS_FOUND"` and abstains from false-claim accusations.
  </action>
  <verify>python -c "import sys; sys.path.insert(0, 'backend'); from app.retrieval.service import retrieval_service; print(retrieval_service)"</verify>
  <acceptance_criteria>
