<task type="auto">
  <name>Task 2: Implement Lineage Graph Engine and Evidence Assessment Engine</name>
  <files>backend/app/lineage/graph_engine.py, backend/app/lineage/assessment_engine.py, backend/app/lineage/__init__.py</files>
  <read_first>backend/app/models/relationship.py, backend/app/models/assessment.py</read_first>
  <action>
    1. Create backend/app/lineage/graph_engine.py:
       - `LineageGraphEngine`:
         - Uses NetworkX `MultiDiGraph` to assemble the investigation graph:
           - Nodes: `Investigation`, `EvidenceSubmission`, `MediaAsset`, `Claim`, `RetrievedSource`, `Account`.
           - Edges: Typed relationships (`SUPPORTS`, `CONTRADICTS`, `SAME_CLAIM`, `CLAIM_VARIANT`, `HISTORICAL_CONTEXT_CONFLICT`, `REPEATS_SOURCE`).
           - Edge attributes: `edge_nature` (`OBSERVED` vs `INFERRED`), `evidence_id`, `rationale`, `confidence`.
         - Generates node-link JSON payload containing node labels, types, metadata, and edge evidence IDs.
         - Generates chronological investigation timeline sorting capture date, publication date, submission date, and claimed date.
    2. Create backend/app/lineage/assessment_engine.py:
       - `AssessmentEngine`:
         - Goal-backward assessment synthesizing:
           1. Historical context conflicts from `ContextComparisonRecord`.
           2. Source independence from `SourceIndependenceRecord`.
           3. Fact-check ratings and passage stances from `RetrievedSourceRecord`.
           4. Media authenticity signals from Phase 2 / Phase 3 records.
         - Strictly enforces non-conflation and evidence invariants:
           - If `has_historical_context_conflict is True` and media is authentic: assessment is `MISLEADING_CONTEXT`.
           - If verified fact-checks directly contradict the claim: assessment is `CONTRADICTED`.
           - If corroborated by independent primary sources with zero contradictions: assessment is `SUPPORTED`.
           - If sources split (some support, some contradict): assessment is `CONFLICTING_EVIDENCE`.
           - If sources count == 0 or evidence is unverified: assessment is `INSUFFICIENT_EVIDENCE`.
           - If breaking claim with no records: assessment is `UNVERIFIED`.
           - Decouples media authenticity: `MANIPULATED_MEDIA_USED` is recorded in `media_authenticity_signal` without forcing `CONTRADICTED`.
         - Compiles structured unresolved questions for investigators.
  </action>
