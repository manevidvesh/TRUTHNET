<task type="auto">
  <name>Task 2: Implement Lineage Graph Engine and Assessment Engine</name>
  <files>backend/app/lineage/graph_engine.py, backend/app/lineage/assessment_engine.py, backend/app/lineage/__init__.py</files>
  <read_first>backend/app/models/relationship.py, backend/app/models/verdict.py</read_first>
  <action>
    1. Create backend/app/lineage/graph_engine.py:
       - `LineageGraphEngine`:
         - Uses NetworkX `MultiDiGraph` to assemble the investigation graph:
           - Nodes: `Investigation`, `EvidenceSubmission`, `MediaAsset`, `Claim`, `RetrievedSource`.
           - Edges: Typed relationships (`SUPPORTS`, `CONTRADICTS`, `SAME_CLAIM`, `CLAIM_VARIANT`, `HISTORICAL_CONTEXT_CONFLICT`, `REPEATS_SOURCE`).
         - Generates node-link JSON payload containing node labels, types, metadata, and edge evidence IDs.
         - Generates chronological investigation timeline sorting capture date, publication date, submission date, and claimed date.
    2. Create backend/app/lineage/assessment_engine.py:
       - `AssessmentEngine`:
         - Goal-backward assessment synthesizing:
           1. Historical context conflicts from `ContextComparisonRecord`.
           2. Source independence from `SourceIndependenceRecord`.
           3. Fact-check ratings and passage stances from `RetrievedSourceRecord`.
         - Applies strict epistemological rules:
           - If `has_historical_context_conflict is True` and media is authentic: Verdict is `MISLEADING_CONTEXT`.
           - If `contradicting_sources >= 1` from verified fact-checks: Verdict is `VERIFIED_FALSE`.
           - If `independent_sources >= 2` supporting and 0 contradictions: Verdict is `VERIFIED_TRUE`.
           - If sources split (some support, some contradict): Verdict is `CONFLICTING_EVIDENCE`.
           - If sources count == 0 or evidence is unverified: Verdict is `INSUFFICIENT_EVIDENCE`.
         - Formulates explainable summary and compiles unresolved questions for investigators.
  </action>
  <verify>python -c "import sys; sys.path.insert(0, 'backend'); from app.lineage.graph_engine import lineage_graph_engine; print(lineage_graph_engine)"</verify>
  <acceptance_criteria>

    - Assessment engine enforces non-conflation invariants and explicit abstention.
  </acceptance_criteria>
