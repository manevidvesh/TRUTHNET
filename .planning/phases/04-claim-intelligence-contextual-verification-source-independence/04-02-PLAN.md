<task type="auto">
  <name>Task 2: Implement Haversine Geodesic Distance and Context Comparator</name>
  <files>backend/app/context/geodesic.py, backend/app/context/comparator.py, backend/app/context/__init__.py</files>
  <read_first>backend/app/models/context_comparison.py, backend/app/models/evidence.py</read_first>
  <action>
    1. Create backend/app/context/geodesic.py:
       - `haversine_distance_km(lat1, lon1, lat2, lon2) -> float`:
         - Mathematical great-circle distance with radius 6371.0 km.
       - `get_known_location_coordinates(location_name: str) -> Optional[Tuple[float, float]]`:
         - Curated centroid coordinate dictionary for prominent cities / landmarks to compare with EXIF GPS.
    2. Create backend/app/context/comparator.py:
       - `ContextComparator`:
         - `compare_context(db_session, evidence_id) -> List[ContextComparisonRecord]`:
           - Gathers claimed context from `EvidenceSubmission` and its `ClaimRecord`s.
           - Gathers observed technical facts from `ExtractionRecord` (EXIF timestamp, GPS) and historical `MediaMatchRecord`s.
           - Calculates temporal delta $\Delta t$ in days between claimed date and observed EXIF capture date.
           - If $\Delta t < -1\text{ days}$ (claimed event allegedly happened *before* photo capture) or $\Delta t > 30\text{ days}$ without archival framing:
             - Flags `HISTORICAL_CONTEXT_CONFLICT`.
           - Inspects caption framing for archival keywords ("Archive", "File Photo", "Flashback", "Retrospective", "Remembering"):
             - If found and dates match historical capture: Flags `LEGITIMATE_ARCHIVAL_REUSE`.
           - Calculates Haversine distance between claimed location coordinates and observed EXIF GPS:
             - If $d > 50\text{ km}$: Flags geographical conflict.
           - If historical data lacks timestamps or GPS: Flags `INSUFFICIENT_CONTEXT`.
           - Generates transparent, evidence-backed explanation citing exact evidence IDs.
    3. Register comparator execution in backend/app/services/pipeline.py.
  </action>
  <verify>python -c "import sys; sys.path.insert(0, 'backend'); from app.context.comparator import context_comparator; print(context_comparator)"</verify>
  <acceptance_criteria>
    - Haversine distance correctly calculates geographical separation.
    - ContextComparator accurately distinguishes conflicts, archival reuse, and insufficient context.
  </acceptance_criteria>
