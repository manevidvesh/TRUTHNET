<task type="auto">
  <name>Task 2: Implement Haversine Geodesic Module and Multi-Signal Context Comparator</name>
  <files>backend/app/context/geodesic.py, backend/app/context/comparator.py, backend/app/context/__init__.py</files>
  <read_first>backend/app/models/context_comparison.py, backend/app/models/evidence.py</read_first>
  <action>
    1. Create backend/app/context/geodesic.py:
       - `haversine_distance_km(lat1, lon1, lat2, lon2) -> float`:
         - Great-circle geodesic distance calculation on WGS-84 sphere ($R = 6,371.0\text{ km}$).
       - `get_known_location_coordinates(location_name: str) -> Optional[Tuple[float, float]]`:
         - Gazetteer dictionary mapping city/state/national landmarks to reference coordinates $(\phi, \lambda)$.
         - Explicitly documents that returned coordinates are geographic centroids (reference points), not forensic event evidence.
    2. Create backend/app/context/comparator.py:
       - `ContextComparator`:
         - `compare_context(db_session, evidence_submission_id) -> List[ContextComparisonRecord]`:
           - Retrieves claimed values from `EvidenceSubmission` and its `ClaimRecord`s.
           - Retrieves observed historical values from `ExtractionRecord` (EXIF timestamp, GPS) and `MediaMatchRecord`s.
           - Evaluates date provenance hierarchy: distinguishes `capture_date` (EXIF), `publication_date`, `archive_date`, `submission_date`.
           - Computes temporal delta $\Delta t$ in signed days:
             - If $t_{\text{claimed}}$ is before $t_{\text{observed}}$ by $> 1\text{ day}$ (alleging event before photo taken): flags physical sequence inconsistency.
             - If $\Delta t > 30\text{ days}$ without archival signals: flags temporal discrepancy.
           - Analyzes caption framing for archival keywords ("Archive", "File Photo", "Retrospective", "Flashback", "Remembering"):
             - Treats archival keywords as contextual signals, not automatic proof.
             - If archival keywords are present AND historical date matches: flags `LEGITIMATE_ARCHIVAL_REUSE`.
           - Computes spatial Haversine distance between reference centroid and EXIF GPS:
             - If distance $d > 50\text{ km}$: flags spatial divergence signal with explanation noting camera position vs event position caveat.
           - Classifies context:
             - `HISTORICAL_CONTEXT_CONFLICT`: Demonstrable temporal or geographic contradiction with historical provenance.
             - `POSSIBLE_CONTEXT_MISMATCH`: Partial or ambiguous divergence requiring verification.
             - `LEGITIMATE_ARCHIVAL_REUSE`: Transparent historical retrospective framing.
             - `CONSISTENT_CONTEXT`: Assertions align with recorded historical facts.
             - `INSUFFICIENT_CONTEXT`: Metadata missing (e.g. stripped EXIF).
             - `CONFLICTING_CONTEXT_EVIDENCE`: Multiple historical records conflict with each other.
           - Records full `reliability_limitations` (sensor caveats, editable EXIF, centroid approximations) and sets `requires_human_review=True`.
    3. Register comparator execution in backend/app/services/pipeline.py.
  </action>
