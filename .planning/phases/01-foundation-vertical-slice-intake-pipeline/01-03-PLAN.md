    Implement backend/app/services/pipeline.py:
    1. PipelineService class:
       - `async def process_evidence_item(evidence_id: str, db_factory)`:
         - Open async session.
         - Retrieve EvidenceSubmission by evidence_id.
         - Update processing_status to "PROCESSING".
         - Run validation routines based on submission_type:
           - For FILE (IMAGE, AUDIO, VIDEO): verify file exists on disk, verify file size matches recorded bytes, verify magic bytes.
           - For URL: attempt head/get request with 5s timeout using httpx. If network error/timeout/status>=400, record error.
           - For TEXT: verify non-empty text.
         - If any check fails:
           - Catch exception, set processing_status = "FAILED", error_message = descriptive error string.
           - Commit changes and exit gracefully without raising uncaught exception.
         - If checks pass:
           - Set processing_status = "COMPLETED".
           - Commit changes.
    2. In backend/app/api/v1/evidence.py:
       - Integrate BackgroundTasks into intake endpoints to trigger `pipeline_service.process_evidence_item` on creation.
       - Add endpoint `GET /api/v1/investigations/{investigation_id}/evidence/{evidence_id}/status` returning:
         - evidence_id, processing_status, error_message, updated_at.
  </action>
