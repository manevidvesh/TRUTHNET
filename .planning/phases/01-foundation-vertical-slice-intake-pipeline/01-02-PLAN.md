  <name>Task 1: Implement Content-Addressed Storage Manager with Streaming SHA-256</name>
  <files>backend/app/core/storage.py</files>
  <read_first>backend/app/core/config.py</read_first>
  <action>
    Implement backend/app/core/storage.py:
    1. StorageManager class:
       - `save_upload_stream(upload_file: UploadFile) -> Tuple[str, str, int, str]`:
         - Stream file contents in 64KB chunks.
         - Compute hashlib.sha256() incrementally.
         - Detect MIME type using filetype library on initial bytes, fallback to upload_file.content_type.
         - Write to temporary file, then atomically move to target path:
           `{settings.UPLOAD_DIR}/{sha256[:2]}/{sha256}{extension}`.
         - Enforce settings.MAX_UPLOAD_SIZE_BYTES (raise HTTPException 413 if exceeded).
         - Return (sha256_hash, mime_type, file_size_bytes, relative_file_path).
       - `save_raw_text(text: str) -> Tuple[str, str, int, str]`:
         - Compute SHA-256 of utf-8 encoded text.
         - Save to `{settings.UPLOAD_DIR}/{sha256[:2]}/{sha256}.txt`.
         - Return (sha256_hash, "text/plain", len(bytes), relative_file_path).
       - `get_file_path(relative_path: str) -> Path`:
         - Validate path to prevent directory traversal attacks (ensure resolved path is within UPLOAD_DIR).
  </action>
  <verify>python -c "import sys; sys.path.append('backend'); from app.core.storage import storage_manager; print(storage_manager.upload_dir)"</verify>
  <acceptance_criteria>
    - StorageManager handles streaming file uploads and computes exact SHA-256 hash.
    - Directory traversal protection prevents path escape.
    - Size limits are strictly enforced.
  </acceptance_criteria>
  <done>StorageManager is implemented with streaming SHA-256 and directory traversal protections.</done>
