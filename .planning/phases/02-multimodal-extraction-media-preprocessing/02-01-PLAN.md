  <files>backend/app/extractors/__init__.py, backend/app/extractors/metadata.py</files>
  <read_first>backend/app/core/storage.py</read_first>
  <action>
    Implement backend/app/extractors/metadata.py:
    1. ImageMetadataExtractor:
       - Uses Pillow to open image safely.
       - Extracts width, height, format, color mode, animated flag.
       - Extracts raw EXIF dictionary via `_getexif()` mapping tag IDs to human-readable tag names.
       - Decodes GPS IFD tags if present into decimal degrees (latitude, longitude, altitude) and records as `observed_gps` (with disclaimer: unauthenticated observed metadata).
       - Decodes DateTimeOriginal: preserves verbatim string. Records `timezone_detected: False`, `timezone_confidence: "UNSPECIFIED_LOCAL"` unless explicit timezone offset tag (0x9288 OffsetTimeOriginal) is present.
       - Records any malformed or decoding errors under `malformed_fields`.
    2. VideoMetadataExtractor:
       - Uses PyAV / OpenCV to probe video container.
       - Extracts width, height, duration_seconds, fps, frame_count, codec_name, bit_rate.
       - Validates unreliable FPS or missing durations.
       - Detects presence of audio streams (`has_audio: bool`, `audio_stream_count: int`).
    3. AudioMetadataExtractor:
       - Uses mutagen / wave to extract duration_seconds, channels, sample_rate, bit_depth, bit_rate, audio_codec.
       - Handles unsupported or corrupt audio files with explicit error capture.
  </action>
