  <files>backend/app/extractors/video_frames.py</files>

  <action>
    Implement backend/app/extractors/video_frames.py:
    1. KeyframeExtractor class:
       - `extract_keyframes(video_path: Path, evidence_id: str, max_frames: int = 15) -> Tuple[List[Dict], str]`:
         - Open video using `cv2.VideoCapture`.
         - Extract total frames, FPS, and duration in milliseconds.
         - Compute target timestamps:
           - Frame 0 (first decodable frame at 0ms).
           - Frame N-1 (last decodable frame at duration_ms).
           - Uniformly spaced intermediate timestamps (e.g. 1 frame/sec, capped so total frames <= max_frames).
         - For each target timestamp, seek using `CAP_PROP_POS_MSEC`, decode frame, and verify decode success.
         - Encode frame as JPEG (quality=90).
         - Save to `data/derived/{evidence_id}/frames/frame_{idx}_{timestamp_ms}ms.jpg`.
         - Compute SHA-256 hash of the JPEG bytes.
         - Record frame metadata: { frame_index, timestamp_ms, width, height, sha256_hash, relative_path, is_boundary_frame: bool }.
         - Record sampling strategy: "FIRST_LAST_AND_UNIFORM_INTERVAL".
         - Include extraction disclaimer: "Sampled keyframes represent discrete observed visual checkpoints and do not establish whole-video authenticity."
         - Safely close video capture handle.
  </action>

  <acceptance_criteria>

    - Captures SHA-256 for every derived frame.
  </acceptance_criteria>

<task type="auto">
  <name>Task 2: Implement PyAV Video Audio Stream Detection and Demuxing</name>
  <files>backend/app/extractors/audio_demux.py, backend/app/services/pipeline.py</files>
  <read_first>backend/app/extractors/video_frames.py</read_first>
  <action>
    Implement backend/app/extractors/audio_demux.py:
    1. AudioDemuxer class:
       - `extract_audio_from_video(video_path: Path, evidence_id: str) -> Optional[Dict]`:
         - Open container using PyAV (`av.open(str(video_path))`).
         - Check `container.streams.audio`. If empty, return None with status "NO_AUDIO_STREAM".
         - If audio stream present:
           - Record stream metadata: codec_name, sample_rate, channels, duration, bit_rate.
           - Create output path: `data/derived/{evidence_id}/audio/extracted_audio.wav`.
           - Demux and decode audio packets, convert to 16kHz mono PCM 16-bit WAV using PyAV `AudioResampler` or native WAV stream.
           - Compute SHA-256 of extracted WAV.
           - Return dictionary: { artifact_type: "EXTRACTED_AUDIO", relative_path, file_size_bytes, sha256_hash, sample_rate: 16000, channels: 1, duration_seconds }.
    2. Update backend/app/services/pipeline.py:
       - For VIDEO submissions:
         - Run `KeyframeExtractor.extract_keyframes`.
         - Run `AudioDemuxer.extract_audio_from_video`.
         - Persist derived artifacts in `DerivedArtifact` table.
         - Wrap audio extraction in try/except: if audio extraction fails (e.g. corrupt audio stream), log warning and continue; video frame extraction still completes successfully.
  </action>
  <verify>python -c "import sys; sys.path.append('backend'); from app.extractors.audio_demux import audio_demuxer; print(audio_demuxer)"</verify>
  <acceptance_criteria>
    - AudioDemuxer detects presence/absence of audio in video containers.
    - Demuxes audio to 16kHz mono WAV when audio stream is present.
    - Audio failures are isolated and do not prevent keyframe extraction.
  </acceptance_criteria>
  <done>PyAV audio demuxing and pipeline integration complete.</done>
