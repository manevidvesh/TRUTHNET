  <files>backend/app/extractors/ocr.py</files>

  <action>
    Implement backend/app/extractors/ocr.py:
    1. BaseOcrEngine (ABC):
       - `is_available() -> bool`
       - `extract_text(image_path: Path) -> Dict[str, Any]` returning { status, text, language, engine, lines, confidence, error }
    2. WindowsMediaOcrEngine (BaseOcrEngine):
       - Uses `winocr` package (calling native `Windows.Media.Ocr.OcrEngine`).
       - `is_available()` returns True if `winocr` is importable and Windows OCR runtime is accessible.
       - Runs real async/sync OCR inference on the target image.
       - Extracts recognized text, bounding boxes, and recognized lines.
    3. TesseractOcrEngine (BaseOcrEngine):
       - Uses `pytesseract` if installed and `tesseract.exe` is found on system PATH.
       - `is_available()` checks `shutil.which("tesseract")` or pytesseract binary check.
       - Runs OCR if available, else raises/reports engine unavailable.
    4. CompositeOcrService:
       - Inspects available engines in priority order: WindowsMediaOcrEngine -> TesseractOcrEngine.
       - If an engine is available, executes real OCR inference.
       - If no engine is available, returns `{ "status": "UNAVAILABLE", "text": None, "engine": None, "reason": "No supported OCR engine found in host environment" }`.
       - NEVER returns synthetic or hardcoded text.
  </action>

       - Instantiate or retrieve active `ExtractionRecord` (version=1, is_active=True).
       - Modality 1: Technical Metadata (Image, Video, or Audio):
         - Wrap in try/except; record metadata or error, set `modality_statuses["metadata"]`.
       - Modality 2: Visual Frame Extraction (Video only):
         - Extract keyframes (first, last, uniform intermediate).
         - Save derived frame artifacts and create `DerivedArtifact` records.
         - Wrap in try/except; set `modality_statuses["frames"]`.
       - Modality 3: Audio Demuxing (Video only):
         - Demux audio if audio stream present.
         - Save derived audio WAV and create `DerivedArtifact` record.
         - Wrap in try/except; audio failure does NOT affect keyframes or metadata.
       - Modality 4: Optical Character Recognition (Image only, or keyframes):
         - Run `ocr_service.extract_text`.
         - Wrap in try/except; set `modality_statuses["ocr"]`.
       - Modality 5: Speech Transcription (Audio submissions or demuxed video audio):
         - If audio submission or demuxed audio exists, run `transcription_service.transcribe`.
         - Wrap in try/except; set `modality_statuses["transcription"]`.
       - Overall status evaluation:
         - If all applicable modalities completed successfully: `COMPLETED`.
         - If at least one modality completed (e.g. metadata) but optional ones were UNAVAILABLE or failed: `COMPLETED` or `PARTIAL` (never fail the whole evidence item unless physical binary is unreadable).
       - Update `ExtractionRecord` with all results, derived artifact IDs, and execution timestamp.
       - Update `EvidenceSubmission` status to `COMPLETED`.
